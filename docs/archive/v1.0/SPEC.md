## 1. 位置づけ

v1.0は、最初期の箱庭シミュレーターを能力選択型のゲームへ発展させ、PCブラウザで一度完成させた版。

2026-08-29のPCブラウザQA checkpointをもって完成版として閉じ、その後のマップ縮小・移動テンポ・HP・繁栄設計の再設計をv1Rへ分離した。

## 2. ラン構造

- 2 SET × 6 STAGE = 12 STAGE
- 各SET開始時にSET能力を1つ取得
- 各SETの残り5回のSTAGE間で通常能力を取得
- SET 2開始時に盤面・初期個体数をリセット
- 取得能力はSET 2へ引き継ぐ
- 通常能力提示は **得点能力1枠 + 生態系能力2枠**

## 5. HP・移動・繁殖

### 草食

- 最大HP: 220
- 初期HP: 110
- 植物摂食回復: +26
- 毎Turn移動

### 肉食

- 最大HP: 310
- 初期HP: 155
- 捕食回復: +105
- 移動機会で50%実移動

### 繁殖

- HPは最大HPを上限とする。
- 摂食・捕食で最大HPへ到達すると繁殖。
- 繁殖後の親HPは最大HPの50%。
- 子の基準HPも最大HPの50%。
- 子HP能力は出生後の子へ加算し、最大HPを上限とする。
- v1.0のこの新HP方式ではHP消費は移動したTurnに発生する。

このHP方式はv1Rで再設計されたため、現在版へそのまま適用しない。

v1.0完成系では7種。

| 能力 | v1.0の役割・値 |
|---|---|
| 時間延長 | 各SETで +2 / +4 / +6 / +8 / +10 / +12秒 |
| 植物察知 | 草食HP25%以下、半径2の植物を探索 |
