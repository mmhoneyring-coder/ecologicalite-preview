01

ゲームガイド

ゲームの流れ

目的

植物・草食・肉食が循環する環境を保ちながら、摂食・捕食・繁殖・生存で得点を積み上げます。個体を直接動かすゲームではなく、能力選択で生態系へ介入します。

プレイ構成

SET2 SET
各SET6 STAGE
1 STAGE25秒
速度1× / 2× / 4×

進め方

1SET開始時に、SET全体の方向性を決めるSET能力を1つ選びます。
2STAGEを再生し、生態系の増減や得点の伸びを観察します。
3STAGE 1〜5の終了後、次のSTAGEへ向けて通常能力を1つ選びます。
46 STAGEで1 SET終了。SET 2は新しい盤面で始まり、取得済み能力は引き継ぎます。
52 SET・全12 STAGEを終えると、合計得点で結果を確認します。
生態系の基本

登場するもの

植物草食肉食死体活動値

食べる・繁殖する・死ぬ

草食は植物を食べ、肉食は草食を捕食してHPを回復します。HPは時間とともに減り、0になると死亡します。食べたときの回復で最大HPに到達すると繁殖し、親と子が残ります。

植物へ戻る循環

自然死した個体は死体となり、死体から植物が生まれます。また、草食の摂食や肉食の捕食で活動値がたまり、一定量に達すると植物が生成されます。

能力の選び方

SET能力

各SETの開始時に1つ選びます。時間、索敵、植物循環、繁殖など、SET全体の戦い方を大きく変える能力です。

通常能力

STAGE間で1つずつ選びます。HP回復、子のHP、植物供給、得点などを強化できます。同じ通常能力を重ねて取得できるものもあります。

考え方

今不足している生き物や植物、得点の伸び方を見て、次のSTAGEで必要な能力を選びます。能力選択がプレイヤーの主な判断です。

得点

得点になるもの

植物摂食捕食草食出生肉食出生草食生存肉食生存

得点の見方

摂食・捕食・出生はSTAGE中に加算され、生存はSTAGE終了時の個体数が得点になります。得点系の能力を取ると対象項目を伸ばせます。細かな点数と計算式は「詳細データ」で確認できます。

画面の見方・操作

見る場所

上部で植物・草食・肉食・現在得点、盤面で生態系の動き、活動バーで植物生成までの進み具合を確認します。個体を選ぶと現在HPを確認できます。

操作

再生 / 停止1× / 2× / 4×個体を選択グラフ詳細結果コピーやり直し最初から

グラフと取得能力

得点グラフでSTAGEごとの伸びを確認でき、取得済み能力は一覧から効果を確認できます。結果コピーでは分析用の結果データをコピーできます。

03

内部仕様

ターン処理

1 Turnの主な順序

Turnを進めた後、植物処理 → 草食処理 → 肉食処理 → 死体処理の順で進みます。草食の出生個体は草食処理後に盤面へ追加され、その後の肉食処理の対象になります。

盤面座標

端の扱い

上下左右の端はつながっています。座標と距離計算はトーラスとして扱い、端を越えると反対側へ回り込みます。

STAGE・SET遷移

マップ拡張

各SETのSTAGE 3終了後、既存個体を維持したままマップだけを拡張します。SET 1は33×21、SET 2は32×20になります。

SET 2

SET 2開始時は30×19の新しい盤面を生成し、植物75・草食7・肉食2から開始します。取得済みの能力状態は引き継ぎます。
